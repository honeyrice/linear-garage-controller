# Attribution and publication scope

This repository documents an independent ESP32 retrofit project for a Linear LDCO800. It is not an official Linear, Espressif, ESPHome, Home Assistant, or Apple product. Product names identify compatible parts and integrations.

No open-source license has been selected for this publication yet. Public availability alone is not a general license to redistribute or sublicense the contents. Dependency packages retain their own licenses and are installed separately; they are not vendored here.

Parts of the enclosure's lid-to-base snap geometry were adapted from external reference models. This publication includes the final V0.27 base and lid meshes, measured dimensions, and mesh validation results. Original reference models and dependent CAD build scripts are not bundled.

Photos show the project's completed assembly. Original camera metadata, private device identifiers, household configuration snapshots, private chat links, and compiled firmware are not distributed. Firmware/YAML names have been normalized for a fresh installation; existing installations should preserve their own identities.
